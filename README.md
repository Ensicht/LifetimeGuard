# LifetimeGuard

版本：0.6.0  
作者：Laz

## 简述

帮助处理《怪物猎人：荒野》中的部分卡加载、模型或贴图一直加载不出来的问题。

有些卡加载是因为读取还没结束，文件就被提前关闭；也可能是贴图读取异常后没有正常结束，让后续模型一直等下去。
安装的松散文件（loose files，通常来自外观 Mod）越多，读取和更换资源的机会越多，也就更容易遇到这类问题。

LifetimeGuard 会保护正在使用的文件，在符合条件时重新读取失败贴图，并修正一些已确认的贴图清理引用问题，可以极大减少出现卡加载的情况。

## 前置要求

- 荒野自带的**原版 DirectStorage 1.2.3 x64**，文件版本 `1.2.2407.1501`。
- **REFramework**。截止本说明完成时，最新版本 REF Nightly 01424 有其他 Pak 加载问题，与一些 Mod 存在冲突，建议不要使用 REF Nightly 01424。

## 安装与使用

1. 下载本压缩包。
2. 通过 Mod 管理器或手动解压安装前置和本包。
3. 在 REFramework 中展开 **LifetimeGuard**，查看各项保护是否就绪。默认中文，可切换 English。
4. 已就绪后自动工作，无需反复操作。非加载时显示“保留失败纹理重读与清理配对”是正常状态。

## 注意事项

- LifetimeGuard 用于保护特定版本的 DirectStorage 与 REFramework 加载 loose files 的机制，这两项前置版本变更可能导致本 Mod 失效，具体以 REFramework 中 LifetimeGuard 的状态为准。
